## Что реализовано на jQuery

| Функциональность | Где в коде | Метод jQuery |
|---|---|---|
| Выпадающее (мобильное) меню | `js/script.js` → раздел 1 | `.slideToggle()` |
| Модальное окно «Оставить заявку» | раздел 2 | `.fadeIn()` / `.fadeOut()`, клик по оверлею/Esc |
| Динамическая галерея из JSON | раздел 3 | `$.getJSON('data/portfolio.json')` |
| Плавное появление карточек портфолио | раздел 3 | `.delay().fadeIn()` |
| Валидация форм (имя, email, сообщение) | раздел 4 | ручная валидация + regex для email |
| Симуляция отправки формы | раздел 4 | `$.ajax()` (POST на тестовый endpoint) |
| Карусель навыков | раздел 5 | кнопки prev/next, точки-индикаторы, автопрокрутка `setInterval` |
| Подсветка активного пункта меню при скролле | раздел 6 | `.scroll()`, `.offset()` |
| Кнопка «Вверх» с плавным скроллом | раздел 7 | `.animate({ scrollTop })` |
| Плавный скролл по якорным ссылкам | раздел 7 | `.animate({ scrollTop })` |

## Как открыть локально
Просто откройте `index.html` в браузере. Для корректной загрузки
`data/portfolio.json` через `$.getJSON` рекомендуется запускать через
локальный сервер (например, расширение Live Server в VS Code), так как
некоторые браузеры блокируют `fetch`/`ajax` к локальным файлам при
открытии через `file://`.
